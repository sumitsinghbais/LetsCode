# LetsCode

LetsCode is a full-stack LeetCode clone that I am building as a personal project to understand and implement real-world full-stack development concepts.

The goal of this project is to build an online coding platform where users can create accounts, solve coding problems, submit solutions, and track their progress.

## 🚀 Project Status

🚧 **Currently under development**

The backend foundation and user registration flow are currently being developed.

## 🛠️ Tech Stack

### Backend

- MongoDB
- Mongoose

### Planned Technologies
- Redis
